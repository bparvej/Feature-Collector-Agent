# Installation Guide

## Prerequisites

- Node.js 18 or newer
- npm 9 or newer

## Setup

1. Clone or download the repository.
2. Run npm install.
3. Run cp .env.example .env and add a Gemini API key if needed.
4. Start the app with npm run dev.

## Local development

- Frontend: http://localhost:5173
- Backend: http://localhost:4000
