# Feature Specification

## Core features

- Project dashboard with KPIs and status cards
- Project CRUD and analysis history
- Drag-and-drop multi-file upload
- Supported document parsing and validation
- AI configuration panel with provider/model selection
- Analysis orchestration and quality validation
- Feature inventory with edit and delete controls
- Test scenario creation and filtering
- Functional test case management
- Traceability and evidence viewing
- Coverage and gap analysis
- JSON, CSV, PDF, and HTML export

## Non-goals for Agent 1

- Browser automation execution
- Playwright test execution
- API test execution against live apps
- Credential-based website discovery or login automation
