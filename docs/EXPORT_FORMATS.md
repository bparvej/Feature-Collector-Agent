# Export Formats

## JSON export

Includes project metadata, analysis version metadata, source documents, requirements, features, tests, and evidence references.

## CSV export

Well-formed CSV output for feature inventory and test-case analysis, compatible with Excel and protected against standard formula injection by escaping field content.

## PDF export

A plain text-based PDF export is generated for local usage and can be opened by standard PDF viewers.

## HTML export

Standalone HTML presents the analysis in a styled report with sections and print-friendly layout.
